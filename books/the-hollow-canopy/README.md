# The Hollow Canopy

**Slug:** `the-hollow-canopy`  
**App:** `/books/the-hollow-canopy`

Adult BL omegaverse expedition novel. One complete story, 45 chapters, five acts.

| Layer | Path |
|-------|------|
| Bible | `books/the-hollow-canopy/knowledgebase/` |
| Prose | `books/the-hollow-canopy/content/chapters/` |
| Seed | `books/the-hollow-canopy/seed/` |
| Cover | `public/assets/covers/the-hollow-canopy.svg` |

Major Calder Rhys, alpha, is assigned to protect Dr. Ivo Maren, omega, in the Orrocanopy. Ivo knows who Calder is. Calder does not. Under Qalen-Sar, the Selenqar did not die in a war. They asked a question, and the Marrow is still trying to finish the answer.

```bash
npm run seed:sync
npm run seed:chapters -- --book the-hollow-canopy
```
