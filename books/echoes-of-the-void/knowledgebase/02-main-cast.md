# Main Cast — The Ten

All **17 at Academy arrival**. Same cohort year. Equal narrative importance over the series.

## The Five Omegas

### Elarion Voss (protagonist)
- **House:** Voss (minor, loyal, cold)
- **Path:** Mage (basic talent)
- **Role:** Unwanted spare; transmigrator; secret looper
- **Arc:** Kind → strategic → ruthless → the End
- **Look:** Forgettable average; neither beautiful nor ugly

### Lirien Thorne
- **House:** Thorne (diplomats, spies)
- **Path:** Mage (illusion)
- **Role:** Charismatic schemer; silver tongue
- **Arc:** Ambition vs genuine attachment; may betray or aid depending on loop

### Seraphiel Kane
- **House:** Kane (healers)
- **Path:** Mage (healing)
- **Role:** Moral center; empathy as strength
- **Arc:** Fractures when healing cannot fix politics

### Vesper Quill
- **House:** Quill (information brokers)
- **Path:** Skill user (shadow, foresight hints)
- **Role:** Quiet observer; secrets
- **Arc:** Knows too much; choices between warning and silence

### Aurelius Dawn
- **House:** Dawn (border warriors)
- **Path:** Skill user (martial)
- **Role:** Fierce warrior omega; challenges stereotypes
- **Arc:** Glory vs survival; respect for Elarion's hidden steel

## The Five Princes (Valerius brothers)

### Draven — Crown Prince
- **Path:** Skill user (command, fire affinity)
- **Personality:** Charismatic, possessive, politically sharp
- **Default loop romance:** Often first prince Elarion pursues

### Kael — Second Prince
- **Path:** Mage (strategy, runes)
- **Personality:** Scholar-strategist; patient chess-mind

### Thorne — Third Prince
- **Path:** Skill user (assassination, shadow)
- **Personality:** Brooding; secrets within secrets

### Riven — Fourth Prince
- **Path:** Skill user (storm, battle)
- **Personality:** Wild, impulsive loyalty, battle-lust

### Soren — Fifth Prince
- **Path:** Mage (divination, prophecy-adjacent)
- **Personality:** Quiet visionary; unsettling calm

## Key supporting

- **Emperor Valerius** — engineer of succession games
- **Archmage Valeria** — stern Academy instructor (beta)
- **House heads** — political pressure on all ten mains
